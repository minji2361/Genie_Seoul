# 관리자 페이지, 이렇게 만듭니다 (쉬운 설명)

작성일: 2026-08-16
※ 개발자용 상세 문서는 `admin-page-plan.md`에 별도로 있습니다. 이 문서는 개발을 잘 모르는 분도 내용을 이해하고 의견을 주실 수 있도록 쉽게 풀어쓴 버전입니다.

## 왜 필요한가요?

지금은 두 가지가 불편합니다.

1. 상담사(코치)들이 등록한 인터뷰·상담 대상자 정보가 계속 쌓이는데, 오래된 정보를 정리하려면 개발자가 직접 손을 대야 합니다.
2. 홈페이지에 뜨는 팝업(문구, 이미지, 켜고 끄는 것)을 바꾸려면 그때마다 개발자가 코드를 고치고 배포해야 합니다.

이 두 가지를 **운영진이 별도의 "관리자 화면"에서 직접 처리**할 수 있게 만드는 게 이번 기획의 목표입니다.

## 지금은 어떤 상태인가요?

- 지금은 상담사 전용 로그인 하나만 있어서, 로그인하는 사람 모두가 같은 권한을 갖습니다. 즉 상담사 누구나 (원한다면) 전체 데이터를 보고 지울 수도 있는 상태입니다.
- 관리 화면이 하나 있긴 하지만, 지금은 "목록을 보는 것"만 되고 "정리(삭제)"는 안 됩니다.
- 홈페이지 팝업은 문구·이미지가 코드에 박혀 있어서, 바꾸려면 개발자가 수정해서 다시 배포해야 화면에 반영됩니다.

## 무엇이 새로 생기나요?

### 1) 관리자 계정을 따로 만듭니다

- 상담사 로그인과는 **별도로 "관리자" 계정**을 하나 만듭니다.
- 관리자 계정으로 로그인해야만 관리자 화면(데이터 정리, 팝업 관리)에 들어갈 수 있습니다.
- 일반 상담사는 지금처럼 본인 담당 대상자 화면만 보이고, 관리자 화면 메뉴 자체가 안 보입니다.

### 2) 오래된 데이터를 관리자가 직접 정리할 수 있습니다

- 관리자 화면에서 등록된 지 오래된 데이터(1주 지남 / 2주 지남 / 3주 지남 / 그 이상)를 골라서 볼 수 있습니다.
- 목록에서 여러 건을 체크해서 한 번에 지울 수도 있고, **"한 달 지난 것 한 번에 지우기" 버튼**도 만들어서 편하게 정리할 수 있습니다.
- 실수로 지우는 걸 막기 위해, 지우기 버튼을 누르면 **"정말 지울까요?"를 두 번 확인**받습니다. 몇 건이 지워지는지도 그때 같이 보여줍니다.
- 어떤 데이터는 계속 보관하고 싶을 수 있으니, **"보관" 체크박스**를 만듭니다. 체크해두면 그 데이터는 상담사도, 자동 정리에서도 지워지지 않습니다.
- 참고: 지금도 상담사가 본인 데이터를 직접 지우는 기능은 있습니다(자기 담당 건만, 확인창 한 번 뜨고 바로 삭제). 이건 지금처럼 그대로 두고, "보관" 체크가 된 건만 예외적으로 상담사도 못 지우게 막습니다.

### 3) 홈페이지 팝업을 관리자 화면에서 바로 바꿀 수 있습니다

- 관리자 화면에 팝업 관리 메뉴를 만듭니다.
- 여기서 팝업 문구, 이미지, **켜기/끄기**를 직접 바꿀 수 있고, 저장하면 바로 홈페이지에 반영됩니다. (개발자가 코드를 고칠 필요 없음)
- "오늘 하루 안 보기" 버튼처럼 방문자가 직접 끄는 기능은 지금처럼 그대로 유지됩니다.

## 화면은 대략 이런 흐름입니다

**관리자 로그인 → 관리자 화면**
- 위쪽에 "인터뷰 / 대시보드 / 전체" 고르는 버튼과, "1주 / 2주 / 3주 / 그 이상" 기간을 고르는 버튼이 있습니다.
- 조건을 고르면 그에 맞는 데이터 목록이 표에 쭉 나옵니다. (이름, 담당 상담사, 등록일, 며칠 지났는지, 보관 체크박스)
- 지우고 싶은 항목을 체크하고 "선택 삭제"를 누르거나, "한 달 지난 것 한 번에 지우기" 버튼을 누릅니다.
- 두 번 확인 후 실제로 삭제됩니다.

**관리자 화면 - 팝업 관리 탭**
- 팝업 제목, 설명 문구를 입력하는 칸
- 팝업 이미지를 올리는 칸 (미리보기 제공)
- 팝업을 "켜짐/꺼짐"으로 바꾸는 스위치
- 저장 버튼

## 결정된 것 / 아직 확인할 것

**이미 결정된 것**
- 관리자 계정은 상담사 계정과 완전히 분리한다.
- 데이터 삭제는 예약해뒀다가 나중에 지우는 방식이 아니라, 확인 두 번 거친 뒤 그 자리에서 바로 지운다.
- 상담사의 기존 삭제 기능(본인 데이터, 확인 한 번)은 그대로 둔다. 단, "보관" 체크된 건은 예외로 막는다.
- 관리자는 여러 건을 한 번에 선택해서 지울 수 있고, "한 달 지난 것 한 번에 지우기" 버튼도 만든다.
- 관리자 화면은 인터뷰/대시보드를 나눠 보여주는 대신, 한 화면에서 조건(종류, 기간)으로 걸러서 본다.

**아직 확인이 필요한 것**
1. "그 이상" 기간 구분이 정확히 몇 일부터인지 (지금은 3주 넘은 것부터로 가정하고 있습니다) — 맞는지 확인 부탁드립니다.
2. 관리자 로그인 화면을 상담사 로그인과 같은 화면에서 처리할지, 완전히 다른 페이지로 만들지는 개발하면서 정할 예정입니다.
3. 지금도 상담사가 데이터를 지울 때 관련 이미지 파일(서명 등)이 안 지워지고 남는 문제가 있는데, 이번 작업과 별도로 같이 정리할지 확인이 필요합니다.
